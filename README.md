Interested in understanding systems from the **hardware and firmware layers up through the operating system and application stack**, with a particular focus on security and privacy.

### 🔐 Cybersecurity

- Boot-chain integrity and tampering techniques
- Hardware attack surfaces and physical attacks
- Digital forensics and incident investigation
- Reverse engineering and binary analysis
- Privacy-preserving systems and data protection

### 🌐 Networking

- Self-hosted infrastructure
- Network architecture and protocols
- Network security and traffic analysis
- Linux networking and network services

### ⚙️ Engineering

- **Electronics:** PCB troubleshooting, component-level repair, real-world microsoldering
- **Embedded systems:** firmware and hardware-software interfaces
- **CAD:** mechanical design for electronics and custom hardware
- **Machine learning:** neural networks and model experimentation

### Selected Work

**[CNN 3D Visualization](https://github.com/ste-t/cnn-web-3d-vis)**\
Interactive visualization of the inner workings of a Convolutional Neural Network in 3D.

**[From Laptop to Rack-Mounted Server](https://blog.tste.dev/en/posts/laptop-to-rack-mounted-server)**\
A multidisciplinary hardware project combining hardware reverse engineering, electronics, microsoldering, programming, CAD, and 3D printing to transform an old laptop into a custom rack-mounted server.

**[Running a Private Email Server](https://blog.tste.dev/en/posts/email-server)**\
Building and operating a self-hosted mail server, covering the infrastructure and practical considerations involved in running email independently.
